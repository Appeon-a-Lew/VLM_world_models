# physwm dashboard (GitHub Pages)
Static viewer for the physwm tabletop-push corpus. All data streams from the
Hugging Face dataset `Appeon-a-Lew/physwm-tabletop-pushes` (see config.js).
Source: https://github.com/Appeon-a-Lew/VLM_world_models (scripts/dashboard_static).

The [M0 results page](m0/) shows the push screen, training curves, and the
follow-up prompt diagnostic from saved experiment scores. Its PNGs are rendered
by `scripts/export_m0_visuals.py` in the experiment workspace.
