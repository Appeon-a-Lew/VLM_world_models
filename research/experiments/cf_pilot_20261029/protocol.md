# Matched counterfactual pilot: frozen protocol, 2026-10-29

This is a diagnostic pilot, specified before inspecting its model predictions. It is not a powered confirmatory study or a novelty claim. Record the protocol, generator/evaluator source hashes, resolved configuration, dataset manifest, checkpoint/config/weight hashes and prediction-file hashes with the run. Freeze those artifacts before inference; preserve unsuccessful runs and explain deviations separately. No numerical outcome is asserted here.

## Cohort and interventions

Generate exactly 100 held-out scene families with `configs/sim_train.yaml`, split `val`, seed start `9901000`, and six branches per family: original, reversed direction, half impulse, double impulse, target recolor, and camera elevation. The generator's seed-only split rule selects validation seeds `9901000, 9901005, …, 9901495`; the fixed cohort contains 600 episodes. Confirm these seeds are unused by the corrected baseline training/validation data and any subsequent training corpus. Do not substitute easier families, discard large errors or regenerate a family after seeing predictions. A generation/integrity failure blocks this cohort; document and repair the generator before freezing a replacement version.

Each family branches from one settled integration-state snapshot, including initial pose/quaternion and solver state. Target identity, geometry, mass, friction, scene layout and nuisance action-direction jitter are shared. Reverse negates the full sampled direction; half/double scale the original impulse and initial speed by exactly 0.5/2. Recolor changes only target appearance; elevation changes only the camera. Verify the latter two retain exactly identical world trajectories. The broad action labels conceal the sampled within-label direction jitter; that latent jitter is fixed across a family. Effect errors therefore evaluate matched responses under the existing partial action description, not recovery of a fully observed action vector or an irreducible-error estimate.

The elevation branch uses 70 degrees when the original elevation is below 55 degrees, otherwise 35 degrees, preserving azimuth, distance and look-at point. This is a mixture of shifted and familiar elevations, **not a pure OOD-camera test**. Report the two elevation groups and their counts descriptively if inspected; retain the predeclared combined branch result. Do not select one elevation after viewing outcomes.

## Frozen model and execution

Initially evaluate only the completed corrected-baseline **training-seed-1 checkpoint**, explicitly labeled `corrected_sft_seed1`. Its availability does not establish seed robustness, and it must not be presented as the old seed-0 checkpoint or a counterfactually trained model. Use the same frozen SFT/inference source, prompt, decoding settings, parser, units, target horizon and adapter-loading path as the corrected baseline. No architecture, loss, prompt, inference-scale calibration, checkpoint selection or post-hoc rescaling is allowed in this pilot. A later seed-2 result is an additional replication, reported separately without pooling its episodes as independent families.

Run normal-image inference on all 600 episodes, retaining raw responses, parsed coordinates and missingness. Require exactly one Task B prediction per episode before evaluation; if Task A is also generated, retain it for the separate baseline grounding analysis. Retry interrupted inference operationally with the same frozen settings; do not choose among multiple stochastic answers. Use an isolated output root and never overwrite a valid completed prediction file.

## Measurements

Use `physwm.eval.counterfactual` on the complete validation cohort, with the saved checkpoint predictions and `--static --n-boot 2000 --seed 0`. Convert each branch's predictions from its own camera coordinates to world coordinates before differencing. For each of the six branches, report target endpoint error at 1 s, `||p_v − g_v||`. For each non-original branch, report target paired-effect error, `||(p_v − p_original) − (g_v − g_original)||`. Also report true effect magnitude and predicted change magnitude; do not infer a response failure when the true physical effect is small.

Target endpoints and paired effects are the predeclared principal diagnostic outputs, reported for every branch without selecting a favorable aggregate. Report means, medians, 95% percentile confidence intervals, family counts and endpoint/pair missing rates. All-object results are secondary: average objects within each family first, then average families equally. Resample whole families, with replacement, for 2,000 bootstrap draws using seed 0; branches and objects are not independent samples. Intervals describe cohort uncertainty conditional on this checkpoint. They are not simultaneous intervals, do not adjust for multiple comparisons and do not establish training-seed uncertainty or statistical power.

Use the evaluator's fixed 1 m penalty for missing endpoints/pairs and show missingness separately; this finite penalty is not a worst-case error bound. Retain valid-complete-family sensitivity summaries alongside penalized results, with their reduced counts and possible selection bias. No post-hoc filtering or subtraction of grounding error from future error is permitted.

The GT-static predictor holds every object at its initial world position and is the negative control for action responsiveness. It can have perfect recolor/elevation invariance while failing endpoint prediction and physical intervention effects. Accordingly, visual invariance alone is not evidence of physical understanding. Compare endpoint accuracy and effect errors together; report model and static results even when model performance is worse. Do not infer model-versus-static significance from overlap/non-overlap of separately bootstrapped intervals.

## Decision rules after the frozen evaluation

1. **Debug before training** if family completeness, branch identity, action factors, snapshot agreement, visual-branch trajectory equality, camera conversion, or source/checkpoint provenance fails. Inspect raw answers when missingness or implausible scales dominate. Verify parser/units/camera-frame conventions with ground-truth round trips and perfect-prediction controls. Correct a demonstrated implementation error, version all affected artifacts, and rerun the entire cohort; retain the superseded result. Do not fit a scale or translation to pilot ground truth.
2. **Do not claim dynamics improvement from cancellation.** If endpoint errors are large but paired effects look good, inspect whether a shared family-level location bias cancels in differencing. Check saved current-state grounding and world-coordinate branch residuals descriptively. If physical effects are close to static while true effects are appreciable, check whether predictions actually ignore changed action text. A good invariance score or an additive perception/dynamics narrative is insufficient to select a new method.
3. **Train on fresh matched action families next** only after integrity checks pass and a reproducible physical-branch response deficit remains alongside interpretable endpoint accuracy and missingness. Keep the architecture, loss and existing optimization recipe fixed; vary the training examples to include matched reverse/half/double actions. Use disjoint seed-only training families, never these 100 validation families, and document the data/token budget. Evaluate the resulting model on a newly frozen held-out family cohort as well as the original validation splits; this pilot becomes development evidence, not an untouched final test.
4. **Train on fresh visual variants next** if physical responses are credible but recolor/elevation causes substantial world-space inconsistency with unchanged GT physics, after camera/parser checks pass. Keep the same architecture/loss and recipe; use disjoint matched visual training families. Treat the 70/35-degree mixture explicitly. If both physical and visual deficits appear, preserve both findings and preregister a matched-budget data comparison before training rather than choosing an intervention by the most favorable pilot number.
5. **Replicate before expanding scope** when effects are small, noisy, dominated by missingness, or not clearly interpretable from the paired residuals. Run the same frozen evaluation on another independently trained baseline seed and/or a new fixed family cohort within the authorized budget. Do not tune thresholds, select checkpoints, enlarge a favorable subgroup, or claim broad causal generalization from this pilot.

These rules guide diagnosis and the next controlled data intervention; they are not numerical acceptance thresholds. Preserve negative and inconclusive results. No final-test split is generated, accessed or redefined by this protocol.
