# Grounded 3D-Aware Spatial Vision-Language Modeling (GR3D)

## Citation
Cheng, Fu, Ji, Zhu, Zhan, Zhang, Yang, Han, Lu, Molchanov, Nariyambut Murali, Kautz, Wang, Yin, Liu. CVPR 2026 (per arXiv comments, unverified beyond that). arXiv:2605.30307, submitted 2026-05-28. https://arxiv.org/abs/2605.30307 (HTML: https://arxiv.org/html/2605.30307).
**Read on**: 2026-10-25. Read ~100k of 121k characters via a summarising fetch. The Limitations section (6.6) and the tail were not read; some Table 1 column headers could not be mapped, so the Omni3D numbers below are partial.

## TL;DR
GR3D decomposes monocular 3D grounding into region-prompted 2D grounding followed by a 3D box written as text, with focal-length-normalised images and dense point-map auxiliary supervision. The camera-robustness evidence is thin: intrinsics help only modestly and there is no viewpoint ablation.

## Setup / method
- Input: RGB, a 2D region prompt (from implicit 2D grounding), camera intrinsics; visual tokens carry 2D PE plus relative-depth cues.
- Output: text 3D box (xc, yc, zc), (w, h, l), normalised Euler angles; no task-specific head.
- Intrinsic normalisation: resize so W' = (1000/fx)*W, H' = (1000/fx)*H; intrinsics are not regressed.
- Supervision: region-to-3D and text-to-3D; about 100 auxiliary surface points per image from GT or predicted depth; 2D box jitter; stage 2 tunes only the LLM on CoT detection data.

## Key results
- Table 5 (intrinsics): adding normalised intrinsics raises SUN-RGBD AP15 41.24 to 43.49 and AP3D 30.95 to 31.64, called "modest, yet consistent".
- Omni3D (Table 1): GR3D-8B beats Qwen3-VL-4B/8B; the overall column reads 25.40 vs 24.92 (DetAny3D) and 23.26 (Cube R-CNN) (column mapping uncertain).
- No ablation removing the dense point supervision; no viewpoint/elevation experiment. The paper notes Qwen3-VL's 3D predictions are unstable under image-size changes but gives no controlled test.

## Relevance to us
- val_ood_config: it again attacks only the intrinsics side. Our K is constant across episodes, so focal normalisation would be a no-op for us; the elevation/camera-pose shift is the unaddressed gap, as with Jiang et al. (2026_camera_robust_3d_tooluse.md).
- Task A: its decomposition (2D point first, then 3D) is the same as IDEA-014 (u, v, depth). It does not add a new test.
- Supports the claim that Qwen-style zero-shot 3D is fragile to image scaling, consistent with exp002 (zero-shot worse than static).

## Ideas for us
None new. Evidence for IDEA-014/019 only (K-varying inputs help modestly; effect size is small, about +0.7 AP3D on one benchmark).

## Caveats / disagreements
- Static indoor/outdoor detection benchmarks at 4-8B scale, not close-range tabletop primitives with a 2B model.
- Gains from the intrinsics are small, which weakens "K-varying crops will fix config" (IDEA-019) as a primary expectation.
